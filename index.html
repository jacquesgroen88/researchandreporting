How It Works
01 — STRUCTURE
Organised by client
Each client has their own folder. Inside: an overview README and a dated reports directory. New reports are added as dated subfolders.
02 — REPORTS
Self-contained HTML
Every report is a standalone index.html — open in any browser, no login required, no dependencies. Designed to be read and shared.
03 — CONVENTIONS
Dated folder naming
Reports follow YYYY-MM-DD-slug so they sort chronologically. The folder name is the permanent reference for that piece of research.
04 — TYPES
Multiple research formats
Competitor ad intelligence, platform audits, keyword research, funnel analysis, creative swipe files, and market research — all live here.
