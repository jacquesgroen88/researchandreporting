2. Email that actually arrives (do this first)

Current DNS (checked 18 Nov): SPF v=spf1 +mx +a +ip4:102.209.87.152 +include:spf-c.mailbaby.net -all, DKIM selector default present, DMARC p=none. The -all means any sender not listed is rejected, so Brevo must be added before the first email goes out.

  1. Create the Brevo account in Reptilia's name (Willem's email), then add and verify the sender sales@reptilia.co.za, with replies to info@reptilia.co.za.
  2. Add Brevo's DNS records (Brevo › Senders & IP › Domains shows the exact values). Expected SPF: 
    v=spf1 +mx +a +ip4:102.209.87.152 +include:spf-c.mailbaby.net include:spf.brevo.com -all
    Check the include value Brevo shows before saving: older accounts use spf.sendinblue.com. Add the two DKIM CNAMEs and the brevo-code TXT exactly as shown. Squirrel Media manages the DNS.
  3. DMARC: keep p=none but add reporting: v=DMARC1; p=none; rua=mailto:dmarc@reptilia.co.za; fo=1. Move to p=quarantine after 30 clean days.
  4. FluentSMTP: primary connection Brevo SMTP (smtp-relay.brevo.com, port 587, TLS, SMTP key). Fallback connection is the server's own mail. Turn logging on. Failure alert to Diane.
  5. Send a test to Gmail and Outlook, open "show original", and confirm SPF, DKIM and DMARC all say PASS.
  6. WP Mail Logging can then be removed (FluentSMTP logs instead).

3. Ask Squirrel Media for a real server cron

Abandoned-cart capture and the MailPoet timers depend on scheduled tasks. CartFlows' own docs: if the task isn't running, abandoned orders aren't recorded. On a VPS this is a two-minute job for the host:

# wp-config.php
define( 'DISABLE_WP_CRON', true );

# crontab for the site user (every 5 minutes)
*/5 * * * * cd /home/reptiliaco/public_html && /usr/local/bin/php wp-cron.php >/dev/null 2>&1

Path from the Plugins screen: /home/reptiliaco/public_html. The PHP binary path is the host's to confirm.

4. Settings, plugin by plugin

Cart Abandonment Recovery

  • Cart abandoned cut-off: 15 minutes. Exclude orders with status processing or completed.
  • Emails: AC1 at 1 hour, AC2 at 24 hours, AC3 at 72 hours. Paste the HTML from emails/ac1…, ac2…, ac3…. Their merge tags ({{customer.firstname}}, {{cart.product.table}}, {{cart.checkout_url}}, {{cart.coupon_code}}) are this plugin's syntax; confirm them against the plugin's tag list on install.
  • Coupon in AC3: off until Willem approves an amount. If approved: single use, 48-hour expiry, percentage capped.
  • Admin notification: on, to the shop, for recovered carts.
  • Staging test: abandon at the checkout form, and also go to PayFast and close the tab. Both must appear as abandoned.

Back In Stock Notifier

  • Show the form on out-of-stock products (simple and variations). Fields: email, plus an optional WhatsApp number (custom field), and a GDPR/POPIA checkbox: "Email me when this is back. No other marketing."
  • Subscribe confirmation: short, on screen. Restock email: emails/bis-back-in-stock.html (map {product_name}, {product_link} to the plugin's placeholders).
  • Captcha: Turnstile on (bots are 3 in 4 sessions on this site).
  • Test with "hide out of stock items" ON (the current setting). Sold-out product pages are still reachable by URL (checked: the long-haired guinea pig), so the form should show, but confirm it.

MailPoet

  • Sending method: "Other", using the FluentSMTP/Brevo route. Throttle about 150 an hour for the first 2 weeks.
  • WooCommerce: "Opt-in on checkout" on, with label "Send me feed reminders, new animals and specials. Unsubscribe any time." Sync customers to a "WooCommerce Customers" list.
  • Import past buyers into a separate list, "Past customers 2021–2026", from the WooCommerce order export, deduplicated by email. Tag them: feed, smallpets, reptile, repeat (2+ orders), last_order_date.
  • Automations: Welcome (wel-1 at 0 days, wel-2 at +3 days), First purchase (pp-1 at +1 day), Purchased in category Frozen Feed (pp-3-reorder-frozen at +25 days), Purchased in Live Feed (pp-3-reorder-live at +18 days), Order completed (pp-2-review at +7 days, once per 60 days).
  • Footer: real address and one-click unsubscribe (already in every template). Unsubscribes are honoured across all lists.
  • Abandoned-cart automation in MailPoet: off (CartFlows does it).

WooCommerce settings

  • Reviews: switch on, "verified owners only" on. Willem
  • Cross-sells: import Blueprint-Execution/data/leak7-crosssell-map.csv (40 products, from co-purchase history; no live animals as targets) with WP Sheet Editor, which is already installed. Red
  • Low-stock and out-of-stock emails: add the shop's address, not only Diane.
