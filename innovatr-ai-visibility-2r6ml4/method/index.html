01The questions

02Depth

How each engine was asked, and how hard.

Every run was a fresh conversation with no history, so one answer can't influence the next, and no engine knew who was asking. Where the engine can search the web, search was on, so the answers reflect what's online today, not only what the model learned in training. We asked each question three times on the chat engines because their answers change from one run to the next. One answer is a coin toss; three show a pattern.

How each engine was set up

  1. ChatGPT: logged out at chatgpt.com, web search on. Each question typed as a new chat. 3 runs.
  2. Claude: claude.ai in an incognito chat (no memory), web search on. 3 runs.
  3. Gemini: gemini.google.com in a temporary chat, so no history or personalisation, default model. 3 runs. Gemini rarely shows its sources in the answer, so its source count is low. That's how it displays answers, not a sign it didn't search. Two Q12 runs were thrown out and redone because an unsent draft had merged into the question.
  4. Google AI Overviews: the AI summary at the top of a google.com search, set to South Africa and English. 1 run per question, because Google shows the same overview to everyone at the same moment.
  5. Perplexity: not included. It now refuses questions from anyone who isn't signed in. We'll add it from a clean account at the first re-measure.

What we recorded for every answer

  1. Which firms were named, in the order they first appear. A firm counts as named only if the answer text mentions it.
  2. How long the answer was, in characters, so it's clear these were full answers rather than one-liners.
  3. Which websites it cited, where the engine shows them. This is how we know where answers come from: 376 sources in total, 61% of them competitors' own websites.
  4. What it said about Innovatr whenever Innovatr came up, with anything wrong, outdated or conflicting flagged. For example, the 44M panel figure, or the old innovation-agency description.

03The 8 characters

What "8 characters" means.

When you open innovatr.co.za in Chrome, you see the full site: Test24, prices, the panel, case studies. But your server doesn't send that text. It sends an almost empty page plus a JavaScript program, and your browser runs that program to build what you see. That is how React sites work by default.

AI crawlers read pages differently. The bots that feed ChatGPT, Claude and Perplexity read the HTML the server sends and, as far as published tests show, don't run the JavaScript. Google's crawler can run it, but later and not reliably. So for these crawlers, what the server sends is all there is.

The only line that differs between pages is the canonical link. Title, description and body are identical everywhere. So to a crawler, Test24, Test24 Pro and the Pulse reports are seven copies of one empty page.

Check it yourself in a minute

  1. Open innovatr.co.za in Chrome, right-click and choose View page source (or press Ctrl+U). Search the source for "Test24" or "R5,000": neither appears. That source is what the server sends.
  2. Or ask ChatGPT to "summarise the page at https://www.innovatr.co.za/test24-pro". It will say it can't read the content, or describe Innovatr from other websites instead.
Why some engines still know a little. Claude and Gemini repeated some correct Test24 Pro detail. That came from search indexes that rendered your site at some point, and from other sites quoting you, not from reading your site directly. It's patchy, which is why the same engines also describe the old innovation-agency business. The fix is to send the real text from the server (pre-rendering). That's a build change; the design stays the same.
Something we found on 25 November: your tracking is already installed. The page loads Google Tag Manager (container GTM-WV5NKLVG). Inside it is a Google Analytics 4 property (G-4NPGN7XSZM), plus Microsoft Clarity and the LinkedIn Insight tag. So data is probably being collected today, but nobody at Innovatr has access to it. Whoever set it up, possibly a former marketer or a developer, owns the login. If you can recover access, there may be months of traffic history to use as the "before" picture. 05Limits

What this does and doesn't show.

  1. It's one day. AI answers change between runs and from week to week. Treat every number as a count on 18 November 2026. That's why we re-run the same questions monthly instead of quoting one result.
  2. It isn't traffic. It shows what buyers are told, not how many of them ask. Search Console and Analytics fill that gap.
  3. Perplexity isn't in it yet, for the reason above.
  4. Gemini hides most of its sources, so the source analysis leans on ChatGPT and Claude.
  5. Google AI Overviews was checked from a signed-in browser set to South Africa. Overviews can differ slightly by location and account.
