Website Audit

Website Quality — 45 / 100

The site communicates basic practice information but lacks the professional polish, conversion architecture, and trust signals expected of a modern dental practice.

No Clear H1 Tag on Homepage
No H1 heading is visible on the homepage. Google uses the H1 to understand the page's primary topic. Without it, the page loses critical SEO weighting and gives visitors no anchor for what the practice offers.
Add a single, keyword-rich H1: "Trusted Dentist in Pretoria - General, Cosmetic & Children's Dentistry"
No Meta Description
The homepage has no meta description tag. Google will auto-generate one from random page content, resulting in a low-quality snippet that reduces click-through rates from search results.
Write a 155-char meta description: "Tooth Fairy Dental Clinic in Pretoria CBD offers general, cosmetic & children's dentistry. Same-day emergency appointments. Call Dr Lekota: 064 504 3509."
No Contact Form on Homepage
There is no contact form visible on the homepage. Visitors who want to book must navigate to a separate Contact page - each extra click loses potential patients. Industry data shows removing this friction increases leads by 30-60%.
Embed a 4-field booking request form directly on the homepage: Name, Phone, Service, Preferred Time.
No WhatsApp Link Anywhere on Site
WhatsApp is the primary communication channel for South African patients. No WhatsApp link was found in the header, footer, or contact page - a critical missed conversion touchpoint for Gauteng-based mobile users.
Add a floating WhatsApp button (fixed bottom-right) and a tap-to-chat link in the header and contact section.
Screenshot-Named PNG Files as Images

The sitemap contains only 4 URLs. Each service (Implants, Invisalign, Children's, Emergency) deserves its own dedicated page to capture targeted search traffic.

No reviews or testimonials appear on the homepage or services page. Social proof is the most powerful trust signal for a healthcare provider - its absence significantly reduces conversion.

Analytics & Tracking Audit

Analytics & Tracking — 0 / 100

No tracking infrastructure of any kind was detected. Every visitor, every referral source, and every conversion is completely invisible to the practice.

No Google Analytics 4 (GA4)
GA4 is not installed. There is no measurement of traffic volume, traffic sources, page engagement, or user behaviour. The practice has no idea how many people visit the site or where they come from.
Install GA4 via Google Tag Manager. Takes 30 minutes. Provides immediate visibility into sessions, sources, and user behaviour.
No Google Tag Manager (GTM)
Without GTM, every tracking script must be hardcoded into the WordPress theme - a fragile, developer-dependent setup. GTM makes future tag deployment instant and code-free.
Install GTM container first, then deploy GA4, Meta Pixel, and phone click tracking through it.
No Meta (Facebook) Pixel
Without the Meta Pixel, retargeting on Facebook and Instagram is impossible, and Custom Audiences cannot be built. Any future Meta ad campaign starts cold with zero audience data.
Install Meta Pixel through GTM. Begin building website custom audiences now so they are ready when ad campaigns launch.
No Google Search Console Verification
Search Console is free and provides keyword ranking data, crawl errors, and indexing status. Without it there is no way to know which searches are driving traffic or what technical issues Google has found.
Verify via DNS TXT record or HTML file. Link to GA4 property for combined reporting.
No Heatmap or Session Recording Tool
Without Hotjar or Microsoft Clarity, there is no visibility into how users actually interact with the site - where they click, how far they scroll, or where they drop off.
Install Microsoft Clarity (free, unlimited sessions) via GTM. Provides heatmaps, session recordings, and scroll depth data.
Phone Click Tracking Not Active
Both phone numbers are present but phone click events are not tracked. For a dental practice where calls are the primary booking method, this means the site's call-generation performance is completely unmeasured.
Set up GTM click trigger for tel: links. Fire GA4 event "phone_click". Also configure Google Ads call extensions for paid campaigns.
SEO Audit

Search Engine Optimisation — 30 / 100

The All in One SEO plugin is installed but critically under-configured. Core on-page elements are missing, and the content architecture is too thin to compete for high-intent dental queries in Pretoria.

No Schema.org Markup
No LocalBusiness, MedicalBusiness, Dentist, or Organization schema detected. Schema enables rich results in Google (hours, address in SERPs) and is critical for local pack rankings in competitive markets like Pretoria CBD dentistry.
Add Dentist schema with name, address, phone, hours, and geo coordinates via All in One SEO plugin's Schema tab or JSON-LD in the theme.
No Meta Description on Homepage
When no meta description is provided Google selects a random excerpt - often mid-sentence and meaningless. A well-crafted description with a CTA can increase organic click-through rate by 5-15%.
Write unique 155-char meta descriptions for every page. Include "Pretoria dentist", a service list, and a phone number on the homepage.
Image Alt Attributes Likely Missing
All images are named as raw screenshots. These filenames provide zero context to search engines. Google Images is a significant traffic source for dental practices, especially for before/after treatment photography.
Rename all images with descriptive filenames. Add meaningful alt text: "Dr Lekota dental implant procedure Tooth Fairy Dental Clinic Pretoria"
Only 4 Pages - Massive Content Gap
Competing dental practices have 20-50+ pages targeting specific treatment queries. "Dental implants Pretoria", "Invisalign Pretoria", "Emergency dentist Pretoria CBD" are all high-intent queries with zero dedicated pages.
Create one dedicated landing page per service. 800-1200 words targeting a specific geo-modified keyword. 5 pages = 5 new keyword-ranking opportunities.

Update title: "Tooth Fairy Dental Clinic | Dentist Pretoria CBD | Dr. Lekota"
