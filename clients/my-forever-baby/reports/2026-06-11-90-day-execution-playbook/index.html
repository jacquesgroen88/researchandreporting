Phase 1 · Week 1 — Quick wins

Cheap, reversible, high-certainty. Stop the bleeding and fix trust before touching structure. Do not consolidate ad sets yet — that's Phase 2.

Week 1 · Day 1

Get the house in order

~45 min total

1 · Fix the refund-claim mismatch DO TODAY

Multiple ads promise a "7-day refund" while the site says "14-Day Returns." On a R2,000 buy, contradictions kill trust. Align the ads to the (better) site policy.

Ads Manager→ Ads tab → tick each video ad → Edit → Primary text
FIND → REPLACE (in every ad's primary text)✅ 7-day full refund guarantee ✅ 14-day full refund guarantee Affected creatives: Hypermotion – Hope, Hypermotion – Chloe, and any other ad carrying the "7-day" line. Also check the headline/description fields.
  1. Open the active ad set Women with kids 3-8 – Copy → Ads tab.
  2. For each ad, click Edit → scroll to Primary text → replace "7-day" with "14-day".
  3. Click Publish. (Editing text only — keeps the ad's learning.)
Done when: no live ad contains the string "7-day" anywhere in its copy.

2 · Point every link to the high-trust page DO TODAY

Most ad body links go to the bare homepage (no reviews above the fold). The CTA on the winner already uses /pages/shop — make all of them consistent on the stronger page.

Each ad→ Edit → Website URL → and the link inside Primary text
SET AS THE DESTINATION EVERYWHEREhttps://myforeverbaby.co.za/pages/shop
  1. In each ad's Edit view, set Website URL = /pages/shop.
  2. In Primary text, change the in-copy link from MyForeverBaby.co.za to MyForeverBaby.co.za/pages/shop.
  3. Leave the WhatsApp line for now (we address the dual-funnel in Phase 3). Publish.
Done when: every live ad's URL and in-copy link resolve to /pages/shop.

3 · Throttle the budget hog (don't kill it) CARE

"MFB Reaction Video" eats ~51% of spend at 1.91× ROAS — great hook, junk intent (0.35% add-to-cart). On a CBO campaign you can't set ad-level budgets, so you steer spend by pausing the worst and re-enabling proven winners (next task).

Ad set: Women with kids 3-8 – Copy→ Ads tab
  1. Turn OFF Video Ad Unboxing "With Tears" (ad …290581) — 0 sales, 11.6% CTR pure engagement bait.
  2. Turn OFF MFB Unboxing Single Video (…270581) — a thin 1-line boosted status post, no offer/CTA.
  3. Leave MFB Reaction Video ON for now but expect its share to fall once the winners below get traffic. Re-assess in 5–7 days; pause if still <2× while winners climb.
Why not just delete the Reaction Video? Its hook drives cheap reach that can still assist. We demote, don't destroy — and we judge on ROAS after the winners are funded, not before.
Done when: the two zero-sale ads are off; Reaction Video flagged for a 7-day review.

Phase 3 · Weeks 4–8 — Close the cart leak & decide the volume play

Only 1% of landing-page visitors add to cart. Checkout itself is healthy — so this is a belief gap, not a checkout bug. Fix the page, broaden the framing, then make the budget-vs-signal call.

Weeks 4–8

CRO offensive + scaling decision

biggest ROAS lever

12 · Landing page: stack proof above the fold DEV

Cold buyers of a niche R2,000 item need conviction fast.

  1. Add a review/star module above the fold on /pages/shop (e.g. "★4.8 · 1,000+ SA families").
  2. Add an FAQ block handling the real objection: "Is it appropriate / safe / worth it?" + materials, age 3+, care.
  3. Add security & guarantee badges (secure checkout, 14-day refund, free delivery) near the buy button.
  4. Fix the pricing contradiction: footer "From R1,299" vs on-page R2,099+. Make one true number.
Done when: a first-time visitor sees price + proof + guarantee without scrolling.

13 · Broaden the framing beyond "mum → daughter" COPY

Current hero excludes collectors, grandparents, and therapeutic/companionship buyers — a real slice of this market.

  1. Add a secondary hero line / section: "A meaningful gift — for daughters, grandchildren, collectors, and comfort."
  2. Mirror it in one ad variant so targeting + page tell the same story.
Done when: page + at least one ad speak to a broader buyer than just young mums.

14 · Resolve the dual funnel (web vs WhatsApp) CARE

Every ad offers a site link AND WhatsApp; some "sales" are messaging threads, muddying attribution and ROAS.

  1. Pick website purchase as the primary path for cold prospecting ads; remove the wa.me line from those (keep WhatsApp for retargeting/support).
  2. Ensure CAPI / pixel purchase events fire server-side so web sales are fully counted.
Done when: prospecting ads drive one measurable path; attribution stops leaking.

15 · The volume decision (model against margin FIRST) DECISION

At ~7 sales/week the ad set can't exit learning. Meta's #1 lever (+11 pts) is "increase budget." But more spend at 2.4× only helps if margin clears CPA.

Gate: confirm gross margin / COGS before spending. If contribution per sale > ~R900 CPA, scaling is profitable; if not, fix CRO first and don't add budget.
  1. Path A — if margin supports it: raise campaign budget in +20% steps every 3–4 days toward more daily conversions. Don't double overnight (resets learning).
  2. Path B — if margin is tight: keep budget flat; give Meta denser signal by also optimising for Add-to-Cart in a test ad set, or add value rules. Revisit purchase-optimisation once volume rises.
  3. Track CPA and ROAS daily through each step; hold at the budget where ROAS stays ≥ your breakeven.
Done when: a margin-backed budget path is chosen and the first step is live.

16 · Launch Advantage+ Sales (ASC) — the scaling vehicle BUILD

An ASC campaign already sits paused. ASC is the native Andromeda format. Stand it up alongside the manual set, fed by the winners.

+ Create→ Sales → Advantage+ sales campaign
  1. Create with objective Sales, choose Advantage+ sales campaign.
  2. Set the purchase pixel + (optional) existing-customer budget cap if you want new-customer focus.
  3. Load the proven winners + the 2 new angles (tasks 9–10).
  4. Budget: start at parity with the manual set; name it [ASC] Prospecting | Sales | 2026-06.
  5. Run ASC and the manual broad set in parallel for a fair read.
Done when: ASC is live with winning creatives, running beside the manual set.

17 · Shift spend to the winner (ASC vs manual) CARE

  1. After ~2 weeks of parallel data, compare ROAS & CPA: ASC vs manual broad set.
  2. Move budget to the winner in +20% steps; taper the loser rather than hard-cutting.
Done when: majority of spend sits on the higher-ROAS vehicle.

18 · Build the retargeting / retention layer MISSING TODAY

There's no lower-funnel campaign despite a large buyer base — leaving warm money on the table.

Audiences→ Create → Custom Audience
  1. Build Custom Audiences: site visitors (30/60/180d), Add-to-Cart no purchase (14/30d), past purchasers (for cross-sell/accessories).
  2. Create [RETARGETING] Site+ATC+Buyers | Sales campaign with a small budget.
  3. Creative: cart-abandon reminder, social proof, accessory upsell, "build your bundle".
  4. Build a 1% Lookalike of purchasers as a future prospecting expansion (optional, test broad first).
Done when: a retargeting campaign is live capturing warm traffic.

19 · Lock a creative cadence (out-run fatigue) RHYTHM

Frequency is already ~3–4.5 on a finite ZA audience — fresh creative is the antidote.

  1. Ship 3–4 new concepts per week into the winning vehicle (new hooks, UGC, angles).
  2. Retire any ad whose ROAS drops below breakeven for 5+ days; keep the engine stocked.
  3. Maintain a simple swipe file of winning hooks to iterate, not reinvent.
Done when: a weekly creative-refresh routine is running.
