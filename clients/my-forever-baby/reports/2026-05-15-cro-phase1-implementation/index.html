Summary

What Was Done

Phase 1 focused on the five highest-impact, lowest-effort CRO improvements identified in the audit. All theme code changes were made to the Dwell - CRO draft theme and pushed via Shopify CLI. Product template assignments were made in Shopify Admin. Judge.me was installed and seeded with 23 existing customer reviews.

Changes Delivered

Implementation Detail

💬

WhatsApp Floating Button

A fixed-position WhatsApp button was added to layout/theme.liquid — bottom-right, 58×58px, green (#25D366), with a pre-filled message: "Hi, I'm interested in a baby doll from MyForeverBaby." Opens directly to WhatsApp chat with the store number (072 236 5134). Visible on all pages, mobile and desktop.

LIVE layout/theme.liquid · pushed to Dwell - CRO
📢

Marquee Enabled + Text Updated

The homepage marquee section was enabled ("disabled": false) and the stale Christmas copy was replaced with current messaging: "🌸 Free Nationwide Delivery · 14-Day Returns · New Babies Now In Stock · WhatsApp Us: 072 236 5134". Runs on every page load at zero cost.

LIVE templates/index.json · pushed to Dwell - CRO
🧳

Travel Package — Correct Accessories List

Created product.travel-package.json — a dedicated product template with the correct 8-item accessories list hardcoded: Baby Bag, Baby Carrier, 2 Extra Outfits, Baby Toy, Bib, Burp Cloth, Wash Cloth, 3 Nappies. Includes doll disclaimer. Template assigned to the Travel Package product in Shopify Admin.

LIVE templates/product.travel-package.json · assigned in Admin
💄

Pamper Pack — Correct Accessories List

Created product.pamper-pack.json — a dedicated product template with the correct 17-item accessories list: Hairband, Mirror, Brush, Hair Scrunchie, Nail File, Facial Sponge, Bracelet, Earrings, Butterfly Clip, Nail Polish, Sunglasses, Heart-shaped Pen, Finger/toe Separator, Sleeping Mask, Teddy Bear, Vanity Bag, Water Bottle. Includes doll disclaimer. Template assigned in Admin.

LIVE templates/product.pamper-pack.json · assigned in Admin
⭐

Judge.me Installed + 23 Reviews Imported

Judge.me review app installed (free plan). 23 existing customer reviews sourced from Facebook (19) and Google (4) were formatted and imported via direct CSV import. Reviews distributed across all in-stock doll products, weighted toward top sellers. Post-purchase automated email flow configured to collect new reviews going forward.
