Why This Matters When a client logs into their GHL portal, they should only see the features they paid for. A client on the Automation Suite should not see an empty CRM pipeline, unused funnels builder, or social media planner. Seeing unused features creates confusion, support calls, and makes the platform look messy. Every sub-account must be stripped down to exactly what was sold — no more, no less.

3
Step-by-Step Sub-Account Setup
  • 1
    Create the Sub-Account
    In your GHL Agency view, go to Accounts → Add Account. Fill in:
    • Business name (exactly as on the proposal)
    • Business address and phone number
    • Timezone — confirm with Jacques if unsure (South African clients = SAST / Africa/Johannesburg)
    • Industry (e.g. Hospitality, Salon, Restaurant)
    • Upload the client's logo
  • 2
    Set Business Hours
    Go to Settings → Business Profile → Business Hours. Set the operating days and hours based on what the client told us on the onboarding call. This affects automation scheduling and calendar defaults.
  • 3
    Disable Unused Features (Critical)
    Go to Settings → Company Profile → Features / Navigation. Turn OFF every feature not in the client's package using the matrix in Section 2 above. Typical toggle-offs for Automation Suite clients:
    • Opportunities — OFF
    • Email Marketing — OFF
    • Sites (Funnels, Websites, Blogs) — OFF
    • Social Planner — OFF
    • Calendars — OFF
    • Memberships — OFF
    • Affiliates — OFF
    • Payments — OFF
    • Surveys — OFF
    • Content AI — OFF
  • 4
    Add the Client as a User
    Go to Settings → My Staff → Add Employee. Enter the client's name and email address. Set the correct role (see Section 4). The client will receive an email invitation to log in.
    • Role: User (NOT Admin — Admin gives full settings access)
    • Permissions: restrict to features in their package only
    • Do NOT give them access to Automations, Settings, or Billing
  • 5
    Connect WhatsApp Business Number
    Go to Settings → Phone Numbers → Add Number. Use the number Giorgio sourced for this client. Complete the OTP verification when prompted. This is our number — the client does not provide this.
  • 6
    Connect Google Business Profile
    Go to Reputation → Settings → Connect Google. You will need the client to have accepted the Manager invite to their GBP first (Giorgio gets this during the onboarding call). Once accepted, select their listing from the dropdown.
  • 7
    Build Workflows (Internal — Client Does Not See)
    Build all automation workflows based on the package sold. Do not give the client edit or view access to Workflows. These run silently in the background.
    • Automation Suite: pre-check-in WhatsApp, post-checkout review request, NFC bot (happy + unhappy paths), review auto-response
    • + WhatsApp AI: booking inquiry bot + lead handoff notification
  • 8
    Verify the Client's Login View Before Handover
    Log in as the client (or use the preview feature) to confirm they only see what's in their package. Run through this checklist mentally:
    • No empty Opportunities/Pipeline tab visible
    • No Funnels, Social Planner, or Email Marketing in the sidebar
    • Conversations tab shows and works
    • Reputation tab is connected to their GBP
    • Dashboard loads with relevant stats

Client User Role — What They Can and Cannot Do
⚠️
Never add a client as Admin Admin role gives access to sub-account settings, billing, staff management, and integrations. Clients should always be added as a User with restricted permissions. If they need something changed, they contact Giorgio.
Permission Area Client Role Notes
View Conversations (inbox) View + Reply They can see and reply to guest WhatsApp messages
View Contacts View Only See the guest contact list, but cannot bulk-delete or export
Reputation (reviews) View + Reply Can see review dashboard; auto-responses handle replies automatically
Reporting / Dashboard View Only Can see stats but cannot edit reports
Workflows / Automations No Access Hidden from client entirely — Diane manages these
Settings No Access All settings changes go through Giorgio/Diane
Opportunities / CRM No Access Hidden unless CRM package purchased
Billing No Access Never visible to client
Staff Management No Access Never visible to client
Phone Numbers / Integrations No Access These are our infrastructure — client-facing only
